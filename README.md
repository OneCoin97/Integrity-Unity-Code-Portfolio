## 공개 범위

실제 프로젝트의 C# 스크립트 533개, 물리 코드 약 12만 줄 중 시스템 구조와 문제 해결 과정을 확인하는 데 필요한 코드만 선별했습니다.

- 각 폴더의 `README.md`에 설계 의도, 메인 코드와 권장 확인 순서를 정리했습니다.

- 일부 코드는 구조 설명을 위한 발췌본이므로 이 저장소만으로 Unity 프로젝트를 실행할 수 없습니다.

## 프로젝트 구성

| 프로젝트 | 핵심 내용 |
| --- | --- |
| `1. 게임 런타임 코어 시스템` | 게임 전체 흐름과 공용 데이터를 관리하는 런타임 코어 및 GameManager 리팩터링 전후 |
| `2. Save Load 시스템 설계` | 게임 데이터를 저장하고 불러오며 반복 요청을 통합해 비동기로 파일에 기록하는 시스템 |
| `3. FOV 기반 맵 스트리밍 및 오브젝트 풀 최적화` | 38,093개 블록 맵에서 현재 보이는 영역만 실시간으로 생성하고 회수하는 스트리밍 시스템 |
| `4. 모듈형 Unit Component 아키텍처` | 유닛마다 필요한 기능을 컴포넌트로 조립하고 공용 전투 데이터를 함께 관리하는 구조 |
| `5. 모듈형 절차적 맵 생성 시스템` | 시드와 스테이지 조건으로 진행 구조를 생성하고 Road와 Room 파츠를 조립해 맵을 완성하는 시스템 |
| `6. 엔트리 기반 조립형 UI 시스템` | 데이터와 UIEntry를 조합해 텍스트, 이미지, 게이지와 버튼 화면을 구성하는 UI 시스템 |
