실제 프로젝트의 C# 스크립트 533개, 물리 코드 약 12만 줄 중 시스템 구조와 문제 해결 과정을 확인하는 데 필요한 코드만 선별했습니다.

## 프로젝트 구성

| 프로젝트 | 핵심 내용 |
| --- | --- |
| `1. 게임 런타임 코어 시스템` | 이벤트 코어와 책임별 관리자로 분리한 런타임 구조 및 GameManager 전후 비교 |
| `2. Save Load 시스템 설계` | 저장 대상 추상화, 요청 통합, 비동기 쓰기와 안전한 파일 교체 |
| `3. FOV 기반 맵 스트리밍 및 오브젝트 풀 최적화` | 38,093개 블록 데이터의 FOV 스트리밍, 차집합 갱신과 풀 재사용 |
| `4. 모듈형 Unit Component 아키텍처` | Unit 책임 분리, 타입 기반 컴포넌트 조회와 전투 데이터 모듈화 |
| `5. 모듈형 절차적 맵 생성 시스템` | 제약 기반 레이아웃 생성, 경로 탐색과 데이터 파츠 조립 |
| `6. 엔트리 기반 조립형 UI 시스템` | 제네릭 Entry와 데이터 주입으로 구성하는 UI 갱신 구조 |
