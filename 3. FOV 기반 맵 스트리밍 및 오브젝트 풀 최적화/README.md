# FOV 기반 맵 스트리밍 및 오브젝트 풀 최적화

최대 38,093개 규모의 맵 데이터를 FOV 기반으로 필요한 영역만 실시간 스트리밍한 최적화 사례입니다.

- [상세 설계 및 측정 결과](https://app.notion.com/p/3ba650b00a5c815ea9eedde4b3146122)
- '1.Map Streaming': FOV 변경 영역 계산과 스킬 범위 스트리밍
- '2.Object Pool': 블록, 계산용 HashSet 및 FOV 상태 재사용
- '3.Integration': 스트리밍 결과 적용과 맵 수명주기 연동

첨부 코드는 실제 프로젝트의 FOV 시스템 중 물리 블록 스트리밍과 풀 재사용 흐름을 중심으로 선별했으며, 별도의 오브젝트 데이터 스트리밍 분기와 프로젝트 전용 연결 코드는 제외했습니다.
